# Mettaton TV Shows — Android demo
A playable, original fan-made episodic TV adventure prototype, with dialogue choices, cutscenes and a quiz episode. Not affiliated with Undertale's creators.

## Build APK on GitHub (phone only)
Upload **the contents** of this ZIP to your repository root, preserving `.github/workflows/android.yml`. GitHub's mobile web upload can be used with a file manager that extracts the ZIP first; uploading the ZIP itself does not trigger the build.
Open **Actions > Build Android APK > latest successful run > Artifacts > MettatonTvShows-APK**. Download the ZIP artifact and extract `app-debug.apk`, then install it on Android.

This is a debug APK, not a Google Play release. It uses original CSS pixel graphics rather than copyrighted sprite assets.
